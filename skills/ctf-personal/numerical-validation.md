# 수학적 모델과 근사 결과 검증

> 후보 지식 문서. 일반 수학·데이터 검증용이며 특정 문제의 정답, 플랫폼 조작, 공격 코드나 자동 실행 절차를 포함하지 않습니다. 이 문서의 작은 예제가 맞는다는 사실은 실제 문제 해결률 개선의 증거가 아닙니다.

## 언제 참조하는가

고정 계수의 모듈러 선형식을 만들거나, 수치 손실·유사도 같은 대리 지표로 결과를 평가할 때 필요한 부분만 참조합니다. 단순히 분야 이름이 같다는 이유로 이 방법을 적용하지 않습니다.

## 1. 선형 모형을 풀기 전에 확인할 조건

입력 벡터 x, 관측 벡터 b, 고정 행렬 A에 대해 `Ax = b (mod p)`가 실제 연산을 나타내는지 먼저 확인합니다. 계수가 x와 무관한지, 모듈러스가 무엇인지, 연산 순서에 따른 절단·부호·오버플로가 있는지 구분합니다. 상수항 c가 있는 affine 모형은 `Ax = b - c`로 다룹니다.

소수 p에서만 모든 0이 아닌 원소가 역원을 갖는 체의 선형대수를 그대로 적용할 수 있습니다. 합성수 모듈러스, `mod 2^w`, 정수 나눗셈·비트 연산을 같은 체로 취급하지 않습니다. 곱 `x_i*x_j`, 입력 의존 계수·분기 등이 있으면 별도 증명 없이 선형이라고 가정하지 않습니다. 몇 개 표본에서 가법성이 맞는 것은 전체 선형성의 증명이 아닙니다.

희소한 누적 항으로 A를 구성할 때 같은 위치의 계수는 덮어쓰지 않고 더한 뒤 해당 모듈러스로 정규화합니다. 입력·출력 인덱스와 원래 연산을 연결한 표를 보존합니다.

## 2. 해가 있는지, 유일한지 구분하기

소수체에서 미지수 수가 n일 때 다음을 구분합니다.

| 조건 | 의미 |
|---|---|
| rank(A) < rank([A\|b]) | 해 없음 |
| rank(A) = rank([A\|b]) = n | 유일해 |
| rank(A) = rank([A\|b]) < n | 자유변수가 남음. 임의 한 해를 유일해로 부르지 않음 |

분야나 파일 형식 대신 위 전제가 성립하는지에 따라 방법을 선택합니다. 합성수 모듈러스에서는 이 표를 그대로 사용하지 않습니다. 예를 들어 `2x = 2 (mod 4)`는 x=1,3 두 해를 갖지만 2의 역원은 없습니다. 이를 일반적인 피벗 나눗셈으로 해결하려고 해서는 안 됩니다.

### 독립적인 작은 예제

`p=7`, `A=[[2,1],[1,3]]`, `b=[3,3]`이면 determinant는 5로 0이 아니며 유일해는 `[4,2]`입니다. 대입하면 `[10,10] mod 7 = [3,3]`입니다.

`A=[[1,2],[2,4]]`에서는 두 번째 행이 첫 행의 두 배입니다. b가 `[3,6]`이면 7개의 해가 있고, `[3,0]`이면 해가 없습니다. 성공한 한 해만 출력하지 말고 일관성과 자유변수를 먼저 구분합니다.

## 3. 모델 검증과 해 검증을 분리하기

`Ax-b=0`의 잔차 확인은 추출한 모형 안에서 해가 맞는지 확인할 뿐, A가 원래 계산을 정확히 표현한다는 증거는 아닙니다.

- **모형 검사:** 소유한 독립 참조 계산과 A가 같은 입력에서 같은 출력을 만드는지 대조합니다. 표본 일치는 표본 범위의 근거로 남깁니다.
- **해 검사:** 얻은 x를 원래의 정의된 계산과 전체 조건에 대입합니다. 풀이 때 사용한 잘못된 추출 코드를 검증기에 그대로 복사해 같은 오류를 반복하지 않습니다.
- **목표 검사:** 유효한 중간값·잔차 0·완료 메시지와 원래 목표 충족을 구분합니다. 별도 정답 판정이 필요한 과제라면 그 근거가 없는 결과는 후보로 남깁니다.

검사 도중 원래 입력이나 기준 출력을 고쳐 일치시키지 않습니다. 독립 검증이 불가능하면 그 한계를 기록합니다.

### 상태를 갱신하는 계산의 관측 시점

상태가 바뀌는 계산에서는 로그 필드의 이름 대신 값을 읽은 코드 위치를 확인합니다. 명령 전·쓰기 후·구간 끝을 구분하고, 별도 진단 필드가 실제 연산의 피연산자인지도 확인합니다. 읽는 셀과 쓰는 셀이 겹치면 쓰기 뒤의 값을 이전 값으로 쓰지 않습니다. 원시 관측은 보존하고 코드 순서로 도출한 이전 값은 전제와 함께 따로 표시합니다.

초기 상태 S와 연산마다 갱신되는 상태를 구분합니다. 어떤 값이 계속 S의 값이라고 하려면 해당 경로에서 그 셀을 바꾸는 직접·간접 쓰기가 없다는 근거가 필요합니다. 특정 로그에 쓰기가 없거나 두 경계의 값이 같다는 사실만으로 중간 변경의 부재를 단정하지 않습니다. 분기도 실제 선택 시점의 상태로 설명합니다.

자료가 부족하면 피연산자를 변수로 남깁니다. 결과에서 역산한 입력이나 기대 출력의 복사를 독립 검증으로 사용하지 않습니다. 필요한 최소 관측이 허용된 경우에만 입력·관측 경계·중단 조건을 먼저 고정합니다. 예측은 진입 상태로 계산하고 기대값은 별도로 관측한 종료 상태에서 읽으며, 일치한 셀·구간 밖으로 결론을 확대하지 않습니다. 같은 입력의 추가 관측은 새 사실이 될 수 있지만 미노출 표본은 아닙니다.

**제한된 근거 사례:** [#550의 A49 경계 관측](https://github.com/MyeongJong03/dding-ctf-lab/blob/6d54f152a0ad614175f4d919d8f5035a78e5cab6/docs/pilots/dreamhack-20260929.550-forward-arithmetic/boundary-observation-20260929/BOUNDARY_OBSERVATION.md)은 기존 정방향 함수의 예측을 별도로 관측한 구간 종료와 대조하고, 이후 테이블의 보존을 확인한 한 건입니다. 관측 원문은 비공개이고 외부 검토는 코드·요약·출처 연결에 한정됩니다. 원본 프로그램 전체의 동등성·문제 해결·성능 개선을 뜻하지 않습니다. 구체적인 주소나 상수를 다른 작업의 규칙으로 옮기지 않고, 필요한 경우 기존 메모에 관측 시점·가정·미확인 범위만 짧게 연결합니다.

## 4. 작은 손실은 정확한 결과와 같지 않음

평균 오차, 재구성 손실, 시각적 유사도는 각각 지정된 지표입니다. 이 값이 작다고 정확한 문자열·클래스·모든 제약의 일치가 증명되지는 않습니다.

예를 들어 기준 `[0,0,0,1]`, 후보 `[0,0,0,0.99]`의 평균제곱오차는 0.000025지만 정확한 벡터 일치는 아닙니다. 반올림이나 임계값이 허용되는지는 사전에 정한 과제의 판정 규칙으로 결정해야 합니다. 결과에 맞춰 규칙을 바꾸지 않습니다.

모형 선택·임계값 조정에 사용한 자료와 최종 검증 자료를 구분합니다. 같은 변환·정규화·문자 매핑을 적용한 독립 검증 자료에서 실제 목표 지표를 확인합니다. 후보 선택에 최종 검증 자료를 반복 사용했다면 더 이상 미노출 검증으로 부르지 않습니다. 동일 입력의 반복 성공은 독립 표본 수가 아닙니다.

### 공간별 교정에서 국소성을 가정하기 전에

입력의 한 위치만 바꾸면 대응 출력 위치만 달라진다는 가정은 선형성이나 작은 재구성 손실만으로 성립하지 않습니다. 위치별 교정·부분 대응표에 이 가정이 필요할 때는, 같은 입력을 같은 초기 난수·설정으로 반복한 차이와 국소 입력 변경의 영역 밖 차이를 구분합니다. 이는 필요한 경우 선택하는 검증 방법이며 모든 작업에 새 실험을 강제하는 절차가 아닙니다.

외부 영역의 제곱 변화량 비율만으로 영향의 강도를 비교하지 않습니다. 영역의 셀 수·면적과 셀당 정규화 RMS를 함께 봅니다. 영역 밖 변화가 관측됐다는 사실은 전역 균일성, 모든 위치의 강한 결합, 역복원 불가능성이나 특정 방법의 우월성을 증명하지 않습니다. 차이가 작아도 표본 밖의 독립성이 증명되지는 않습니다.

**제한된 관측 사례:** [#854 통제 대비와 저장 배열의 공간 분석](https://github.com/MyeongJong03/dding-ctf-lab/blob/504691253da15f457958d9705727c29db4df13ce/docs/pilots/dreamhack-20260927.854-context-forward-research.md)은 SD1.5 미러의 고정 구성에서 중앙 64×64 픽셀만 바꾼 한 대비입니다. 최종 latent의 중앙 제외 영역(d=0) 정규화 RMS는 1.287273, 가장 먼 거리대(d=17–27)는 0.347022였습니다. 먼 거리대의 42.36% 에너지는 56.93% 면적과 함께 해석해야 합니다. 원래 가중치·환경 동등성은 미검증이고 거리 분석은 사후 기술통계입니다. 이 값이나 해당 실험의 문턱을 다른 문제의 보편 기준으로 복사하지 않습니다.

실제 적용 시에는 이미 있는 작업 메모에 필요한 독립성 가정, 이를 지지·반박하는 근거와 남은 한계를 짧게 연결합니다. 근거 없이 독립 교정이 성립한다고 진행하거나, 반대로 이 사례 하나로 교정·복원 가능성을 배제하지 않습니다. 결과 검증 방식에 관한 지식이며 새로운 해결 성적이나 속도 개선의 증거는 아닙니다.

## 5. 재사용 지식의 유지 원칙

새 지식은 후보 작성 → 기존 내용과 중복 확인 → 적용·비적용 조건 확인 → 원문·비밀값 제외 → 독립적인 작은 예제 검산 → 검토 브랜치/PR 순서로 관리합니다. 기존 내용과 같으면 중복 문서를 만들지 않습니다.

저장소 반영, 사용자 검토, 설치, 실행에서 실제 참조된 사실은 별개 상태입니다. 평가 도중 설치본을 바꾸지 않고, 이미 학습·검토한 문제를 이후 미노출 표본이라고 부르지 않습니다. 실제 사용 효과는 별도의 동일 조건 비교로 판단하며 예제 수·문서 수로 대신하지 않습니다.
